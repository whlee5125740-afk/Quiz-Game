# 나만의 4지선다 퀴즈 게임 (Quiz-Game)

Python의 기본 문법, 클래스, 파일 입출력과 Git의 변경 이력 관리를 연습하기 위한 **터미널 기반 4지선다 퀴즈 게임**입니다. AI 올인원 교육 과정의 「컴퓨터에게 명령 내리는 말(파이썬) 처음 배우기」 미션을 수행합니다.

> **진행 상태 (2026-11-11):** 핵심 기능의 실제 실행, 자동 테스트 11건 통과, 개발 환경 확인을 완료했습니다. Git 커밋 10개 이상, 작업 브랜치 병합, `pull`, 최종 증빙은 제출 전에 추가 확인할 항목입니다. 이 문서의 완료 여부는 실제 확인 결과에만 근거합니다.

## 1. 프로젝트 개요 및 퀴즈 주제 선택 이유

- **주제:** Python 기초 개념 및 Git 명령어
- **선택 이유:** 이 프로젝트를 처음 학습하는 사람이 `print`, `input`, `list`, `if`, `while`, `json` 등 실제로 사용하는 개념을 퀴즈로 복습할 수 있도록 구성했습니다. 추가 문제를 통해 Git 기본 명령어도 학습할 수 있습니다.
- **목표:** 퀴즈 풀이·추가·목록·최고 점수 조회 기능을 구현하고, 종료 후에도 문제와 최고 점수를 JSON 파일에 유지합니다.

## 3. 설치 및 실행 방법

저장소를 새 PC에 내려받는 경우:

```bash
git clone https://github.com/whlee5125740-afk/Quiz-Game.git
cd Quiz-Game
```

이미 프로젝트를 내려받은 경우 `Quiz-Game` 폴더에서 다음 명령어를 실행합니다.

```bash
python3 main.py
```

메뉴에 표시되는 번호를 입력하고 Enter를 누릅니다.

| 번호 | 기능 | 동작 |
| --- | --- | --- |
| 1 | 퀴즈 풀기 | 등록된 문제를 출제하고 1~4번 답을 입력받아 정답과 점수를 계산 |
| 2 | 퀴즈 추가 | 문제·선택지 4개·정답 번호를 입력받아 저장 |
| 3 | 퀴즈 목록 | 등록된 문제와 4개 선택지, 정답을 출력 |
| 4 | 최고 점수 확인 | 저장된 최고 점수와 등록 문제 수를 출력 |
| 5 | 종료 | 저장 후 프로그램 종료 |

## 4. 프로젝트 파일 구조

```text
Quiz-Game/
├── main.py               # 프로그램 실행 진입점

├── game.py               # QuizGame 클래스: 메뉴, 진행, 저장/복구
├── state.json            # 퀴즈 목록과 최고 점수 (실행 중 저장)
├── tests/
│   └── test_quiz.py      # 표준 unittest 자동 테스트
├── evidence/             # 실제 실행 화면 증빙
├── README.md             # 이 문서
└── .gitignore            # 불필요한 Python 임시 파일 제외
```

`state.json`이 없으면 기본 4지선다 퀴즈 6개로 시작하고 파일을 생성합니다. 문제를 추가하면 퀴즈 수가 증가합니다.

## 5. 주요 코드 구조와 핵심 개념

- **`Quiz` 클래스 (`quiz.py`):** 한 문제의 `question`(질문), `choices`(선택지 4개), `answer`(정답 번호 1~4)를 보유합니다. `show()`는 문제 출력, `is_correct()`는 정답 판정, `to_dict()`·`from_dict()`는 JSON용 자료 변환에 사용합니다.
- **`QuizGame` 클래스 (`game.py`):** 문제 목록과 `best_score`(최고 점수)를 관리합니다. `run()`은 반복 메뉴, `play()`는 퀴즈 진행, `add_quiz()`는 문제 등록, `save()`·`load()`는 파일 저장·읽기 기능을 담당합니다.
- **조건문과 반복문:** 메뉴별 분기에 `if/elif/else`, 반복 메뉴에 `while`, 문제 순회에 `for`를 사용합니다.
- **입력 오류 처리:** 공백, 숫자가 아닌 입력, 범위 밖 숫자는 안내 후 재입력받습니다. Ctrl+C 또는 EOF는 비정상 종료하지 않도록 처리합니다.
- **파일 오류 처리:** JSON 파일이 없으면 기본 데이터를 생성합니다. 손상된 파일은 가능하면 별도 `.bak` 파일로 보관한 뒤 기본 데이터로 복구합니다.

## 6. 데이터 파일: `state.json`

프로젝트 최상위 폴더에 있는 `state.json`은 UTF-8 텍스트 형식의 JSON 파일입니다. JSON은 데이터를 키와 값으로 표현해 다른 실행에서도 다시 읽기 쉬운 저장 형식입니다.

형태 예시(실제 전체 데이터를 그대로 복사한 것은 아님):

```json
{
  "quizzes": [
    {
      "question": "파이썬에서 화면에 글자를 출력하는 함수는?",
      "choices": ["print()", "input()", "len()", "type()"],
      "answer": 1
    }
  ],
  "best_score": 6
}
```

- `quizzes`: 문제 객체들의 목록
- `question`: 문제 내용
- `choices`: 정확히 4개의 보기
- `answer`: 1~4 중 정답 번호
- `best_score`: 지금까지 기록한 최고 정답 개수

**참고:** 위 예시는 파일 형식을 이해하기 위한 축약본입니다. 실제 저장된 문제 수는 프로그램의 목록 메뉴로 확인합니다. 파일을 직접 편집할 때 형식이 깨지지 않도록 주의합니다.
